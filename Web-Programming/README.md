# Web Programming — CGS 1820

Hands-on coursework covering the fundamentals of web programming and web development.

## Technologies

* HTML
* CSS
* JavaScript
* DHTML
* Multimedia

## Course Objectives

### HTML

* Create basic HTML pages
* Use paragraphs, lists, and text markup
* Create absolute and relative hyperlinks
* Add graphics to webpages
* Create forms
* Use tables for webpage layout

### CSS

* Create and use external CSS stylesheets
* Apply CSS for webpage layout
* Create consistent styles across webpages

### JavaScript

* Use JavaScript to add interactivity to webpages

### Multimedia

* Add multimedia content to webpages
* Work with sound and video
